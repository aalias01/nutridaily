About NutriDaily

Personal nutrition tracker. Common foods use USDA-style reference averages; homemade dishes come from a NUTRI import you review. Log by grams, keep an event ledger on device. Optional Google Drive sync. Open source on GitHub. Live: nutridaily.vercel.app.
